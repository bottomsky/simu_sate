# 数据库文档

本项目当前阶段无持久化数据库依赖，暂无实体模型与仓储定义。

- 设计约定（预留）：
  - ORM：Python 侧如需使用，将采用 SQLAlchemy；数据访问遵循仓储模式（Repository）。
  - 事务：通过 Session 上下文管理（try/except/finally），确保异常回滚、连接释放。
  - 连接池：由 ORM/驱动管理连接池参数，避免频繁重连。
  - 安全：所有查询与更新使用参数化，避免拼接 SQL。
  - 性能：为高频检索字段建立索引；避免全表扫描。

若后续引入数据库，我会在该文档补充：
- 关键实体与关系图
- 仓储接口与实现
- 迁移脚本与初始化脚本
- 生产库备份与恢复策略
